# SpotWelding 功率板原理图 A0

打开 [PDF 六页图纸](SpotWelding.pdf) 可分区查看。下载本目录全部文件，使用 KiCad 9 打开 [SpotWelding.kicad_pro](SpotWelding.kicad_pro)。可编辑图纸使用同页网络标号连接，各电容和 MOSFET 单独编号。

| 页 | 内容 |
| --- | --- |
| 1 | 外置充电模块接口、充电隔离、辅助电源 |
| 2 | 24 颗电容、泄放及铜排接点 |
| 3 | 12 颗功率 MOSFET、独立栅阻、焊头接口、分流器与续流 |
| 4 | 数字隔离、四路驱动、驱动域欠压监控 |
| 5 | 电流测量与快速比较、电容过压、充电诊断和温度采样 |
| 6 | 故障锁存、限宽、触发许可、外置 MCU 与测试点 |

A0 用于原理评审。CC/CV 和两路 DC/DC 通过模块端子接入。节点 GND 为电容负极，S_BUS 为分流器上端及驱动域参考。RESET_REQ 为高有效，在外置主控侧适配详细设计中的低有效复位请求。HEALTH 为健康高电平，对应 FAULT_N；READY_N 由主控侧上拉。V_WINDOW 及两个 NTC 的判定由外置主控实现。约 4 kA 的过流门限及约 20.5 V 的过压门限是样机复核起点。需验证保护链最坏延迟、约 2.55 ms 硬件窗口、触发抖动、复位和掉电时序。投板前复核误差、包封引脚、器件额定值、寿命、散热、泄放、模块禁用行为及固定负载测试条件。

KiCad 9.0.2 已导出六区图纸和网表，210 个器件，569 个已连接引脚与设计连接表一致。工程自带抽象符号库，引脚电气类型设为 passive，ERC 主要覆盖连通性，未验证输出冲突、电气性能或生产封装。熔断及续流器件、模块料号和封装待定。3750 A 和成本均待样机及采购验证。
