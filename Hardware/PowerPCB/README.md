A1 用于原理评审。CC/CV 和两路 DC/DC 通过模块端子接入。节点 GND 为电容负极，S_BUS 为分流器上端及驱动域参考。RESET_REQ 为高有效，在外置主控侧适配详细设计中的低有效复位请求。HEALTH 为健康高电平，对应 FAULT_N；READY_N 由主控侧上拉。V_WINDOW 及两个 NTC 的判定由外置主控实现。约 4 kA 的过流门限及约 20.5 V 的过压门限是样机复核起点。需验证保护链最坏延迟、约 2.55 ms 硬件窗口、触发抖动、复位和掉电时序。投板前复核误差、包封引脚、器件额定值、寿命、散热、泄放、模块禁用行为及固定负载测试条件。

KiCad 9.0.2 已导出九张子图及索引和网表，210 个器件，569 个已连接引脚与设计连接表一致。工程自带抽象符号库，引脚电气类型设为 passive，ERC 主要覆盖连通性，未验证输出冲突、电气性能或生产封装。熔断及续流器件、模块料号和封装待定。3750 A 和成本均待样机及采购验证。
